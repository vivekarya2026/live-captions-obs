## Live Captions is now a desktop app

Everything from before, in one window that lives in your menu bar or system tray:

- **Live Captions** page: switch the mic on, pick the language (Hindi → English, English → Hinglish, Auto, English → हिंदी) and the caption style (Word for word, Natural, Simple). See what is on screen right now.
- **Dictation**: hold the shortcut, speak Hindi or English, let go, and the translated text is typed into any app. It uses the same speech model, vocabulary and caption style as the live captions.
- **Vocabulary**: add the names and terms the captions must always get right, right in the app.
- **History**: every dictation is saved, with its recording, to copy or play again.
- Google Docs, OBS and saved session files work as before.

All speech and translation still happens on this computer.
